- Exact validated master and private source tag v0.4.3: a8f8a4968aa121f301c194065fa9c199f4925a77; integration PR #26.

## Evidence and remaining limits

Scoped source/rule/test evidence is stored in config/card_reviews.json and executable QA contracts. Mechanics documentation links shared helpers, consumers, named tests and limitations. Hash-current evidence is reusable; changed dependencies remain visible for revalidation. Preparation/context retrieval is not behavioral approval.

All Radiance cards are available before complete individual clause certification, as authorized. No new blanket FULL certification is claimed. Whole-card gaps, historical bugs and unrelated reports remain open; this release does not declare the entire backlog fixed. Additional-Legend and shared tests cover their stated scenarios, not every possible card interaction.

An early repeated mixed MCTS/ISMCTS four-player smoke run exceeded the existing 60-second whole-game test limit. Standalone repeats completed in 21 and 29 seconds, and subsequent full validation passed, including the exact master package. No gameplay assertion was weakened and no timeout change was made to manufacture a pass. Seed-only exact replay is not claimed for nondeterministic search decisions.

Validation was performed locally on Windows, including isolated installed runtimes. This is not independent second-PC acceptance and does not claim a successful remote GitHub Actions run. Historical assets and upstream remain unchanged.
